# DuckPlayer

This directory contains the DuckPlayer implementation.

## ⚠️ Action Required

To complete the refactoring and file organization, please move the following files into this directory (`DuckPlayer/`) inside Xcode:

1.  `Managers/DuckPlayer/DuckPlayerManager.swift`
2.  `Managers/DuckPlayer/DuckPlayerNavigator.swift`
3.  `Managers/DuckPlayer/DuckPlayerSettings.swift`
4.  `Views/DuckPlayerView.swift`

After moving them in Xcode, you can delete the empty `Managers/DuckPlayer` group.

This manual step is required to ensure the `.xcodeproj` file maintains the correct file references, which cannot be safely automated by the agent.
